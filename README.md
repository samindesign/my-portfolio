# پرتفولیو ثمین

وب‌سایت استاتیک (HTML/CSS/JS) — آماده‌ی انتشار روی GitHub Pages.

## ساختار
- `index.html` — صفحه اصلی
- `css/style.css` — استایل‌ها
- `js/` — core، data، illustrations، case-studies، pages، app (به همین ترتیب لود می‌شوند)
- `demos/` — نمونه‌سایت‌های هر کیس‌استادی (golara، panah، toranj، gozar)
- `assets/img/` — تصاویر نمونه‌سایت‌ها

## انتشار
فایل‌ها را در ریشه‌ی ریپازیتوری آپلود کنید، سپس Settings ← Pages ← Branch: main و پوشه‌ی `/ (root)`.
